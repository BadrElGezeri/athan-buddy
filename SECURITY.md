# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's **Security → Report a vulnerability** form in the `BadrElGezeri/athan-buddy` repository so details remain private until a fix is available.

Include the affected Athan Buddy version, Windows version, reproduction steps, and the security impact you observed. Do not include prayer logs, precise location data, signing credentials, or other personal information.

## Supported versions

Security fixes are provided through the latest stable Athan Buddy release. Older releases should update using **Settings → App updates**.
